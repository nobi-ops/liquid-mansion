# 流動性マンション台帳

都心9区で売買が多く管理がしっかりした中古マンション58棟と、いま売り出し中の部屋の一覧。

- `index.html` … ブラウザで開く画面（建物名＝マンションレビュー、掲載＝不動産ジャパン／アットホームへのリンク）
- `data/buildings.json` … 58棟（2026-10-27 作成。マンションマーケット＋マンションレビューで測定）
- `data/listings.json` … 売り出し中の部屋（2026-10-27 取得・10-28 再確認）

手元で見るとき：このフォルダで `python -m http.server 8000` を動かし、http://localhost:8000/ を開く（ファイルを直接開くとデータが読めない）。
